## HTML-DOUBAN-CARD

It is a fork of https://github.com/TankNee/hexo-douban-card, which was originally designed for Hexo. This package provides a general HTML handler for Douban links.

### Configuration

Set these environment variables before running:

| Variable           | Description                                              |
| ------------------ | -------------------------------------------------------- |
| `DOUBAN_COOKIE`    | Your Douban cookie for fetching data                     |
| `DOUBAN_IMG_PROXY` | Image proxy URL (e.g., `https://images.weserv.nl/?url=`) |

```bash
DOUBAN_COOKIE="your_cookie" DOUBAN_IMG_PROXY="https://images.weserv.nl/?url=" node your-script.js
```
